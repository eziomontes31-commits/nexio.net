Transmisión y conexiones

Perfiles oficiales de Pulso 247

Estos enlaces se mostrarán a los lectores. Para publicar automáticamente, configura también las credenciales privadas indicadas en CONFIGURACION.md dentro de Vercel. No pegues tokens secretos aquí.

Publicación automática

Al aprobar y publicar una noticia, Pulso intentará enviarla a las redes con API configurada en Vercel (Facebook Page, Instagram profesional, X, LinkedIn y/o Telegram). Cada red requiere permisos y credenciales propias. El estado de envío se mostrará al administrador.

Bot periodístico diario

Configura el volumen y las coberturas. El bot busca con Google Search si la IA está disponible; si falla, usa noticias RSS sin IA. Mantiene memoria operativa de enlaces ya procesados y crea borradores para revisión, nunca publica automáticamente.
